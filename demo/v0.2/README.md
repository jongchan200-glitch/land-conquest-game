# 땅따먹기 / CHEW & CLAIM — 플레이 가능한 v0.2

## 사용자 요청에서 고친 부분
- 모바일 화면 **100dvh 전체를 Canvas 세계로 사용**하고 불필요한 페이지 여백·하단 별도 버튼 패널을 없앴음
- 왼쪽 조이스틱과 오른쪽 범용 액션 버튼을 **화면 위에 오버레이**. HUD는 상단에 반투명 압축형.
- 화면 안에서 메뉴를 열어 상점/수납장/규칙/미니맵/자동시연 사용.
- 같은 `main/index.html`만 계속 업데이트하는 운영. GitHub Pages를 `main` / `(root)`로 한 번 활성화하면 GitHub Pages 주소가 고정. Pages 미활성화 상태는 별도 확인 필요.
- 갤럭시 Chrome에서 탭·주소 표시줄은 운영체제/브라우저 UI임. 게임은 100% 뷰포트를 사용하며 화면 내 `⛶ 전체 화면` 버튼으로 전체 화면 API를 요청할 수 있음. 홈 화면 앱 실행은 Pages가 활성화된 HTTPS에서 홈 화면 추가를 사용.

## 이번에 실제 동작하는 기능
- (1) 내 땅 자유 이동, (2) 미점령 땅은 액션 버튼 없으면 이동 불가, (3) 절단선 누적과 연결, (4) 포위 영역 판 낙하/사진 공개
- (5) 포만 게이지 → 자동 소화 + 이동/먹기 금지, (6) 4개 패턴의 곤충형 몬스터 기초 AI, 절단선 공격, 목숨/실패
- (7) 영역·몬스터 포획 코인/XP, 레벨업 시 몸집/시야 변화, (8) 가상 코인 상점의 포만/속도/소화 강화 구매 및 효과 적용
- (9) 테스트용 68% 달성 시 사진 전체 공개→유해나/아니카 기본 카드 획득→다음 스테이지, (10) 획득 카드와 코인·맵·스테이지·강화 localStorage 저장·재접속 복구
- (11) 현재 실제 완성된 얼굴 원본 2개(유해나, 아니카 01), 애벌레 승인 시안에서 분리한 플레이 이미지 활용
- (12) 휴대폰 멀티터치, PC 방향키/WASD+Space, 클릭형 메뉴, 자동 시연, 미니맵
- (13) 기기 홈 화면 바로가기용 manifest/icons 및 네트워크 우선 서비스 워커 (HTTPS 정적 배포 전제)

## 미완료·시안 상태 (완료로 혼동 금지)
- 수일 플레이 가능한 초대형 맵/난이도 및 생태계 밸런스, 8장 화보를 인물별 동일 얼굴로 제작·승인한 최종 에셋, 한국/외국 전체 캐릭터 6~8명 구성
- 희귀/골드 프레임·확률/중복 보상 규칙, 몬스터 완성 애니메이션/4종 정교한 패턴, 상점 가격/강화 능력치 최종 밸런스
- 광고 SDK, Play 결제, Google Play Games 로그인, 백엔드/클라우드 복구, Android 네이티브/스토어 배포. **광고 결제는 전혀 작동하지 않음**
- 원본 사진이 감춰진 조각은 자연 소재 판 텍스처이며, 향후 진짜 월드 스케일·사진 확대와 소화 연출을 사용자 평가로 조정.
