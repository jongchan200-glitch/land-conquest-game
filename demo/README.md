# 땅따먹기 · CHEW & CLAIM 데모 v0.1

- 첫 실제 실행 데모: 2026-11-22
- 이 프로젝트의 가장 최신 디자인·규칙은 Google Drive 인수인계 기준. 파일 주소: https://docs.google.com/document/d/1YHs0SmCZQje8DnYNuusba0i0TW_GMpze466JEC0_eOE/edit
- 기술: HTML5 Canvas + CSS + JavaScript. 이미지 포함 단일 HTML, 인터넷 연결 불필요.
- **실행:** `index.html`을 Chrome으로 열고 `데모 시작`을 누른다.
- PC: 방향키/WASD로 이동, Space(또는 Enter)를 누른 상태에서 바깥 영역을 갉아먹는다. `자동 시연` 버튼은 닫힌 절단선을 만들고 1회 캡처하는 과정을 자동으로 보여준다.
- 모바일: 가상 조이스틱 + 오른쪽 원형 액션 버튼. 화면 회전은 선택 사항. 세로 화면에서는 게임 하단에 두 조작 버튼 배치.

## 구현된 것
1. 내 영역에서는 버튼 없이 이동.
2. 내 영역 외부에서는 액션 버튼을 누르지 않으면 경계에 막힘. 미점령지에서 이동 중에 버튼을 놓아도 이동 중지.
3. 액션 중 미점령 영역을 잘라 내며 잔여 절단 경로 표시, 작은 부스러기/먹기 사운드 재생(브라우저 제한에 따라 소리가 나지 않을 수 있음).
4. 갉아먹은 횟수에 따라 입과 볼이 부풀고 입이 차면 자동 강제 소화 1.85초. 이때 이동/먹기 모두 불가능.
5. 절단선이 기점인 내 영역으로 돌아오면 flood-fill로 완성 구역 판단(임시 '작은 쪽' 선택) 후 판이 통째로 떨어지며 원본 사진 노출.
6. 오프라인 인물 사진 내장, 점령률 표시, 리셋 및 자동 시연.

## 의도적으로 미구현·미확정
- 실제 장기 스테이지 크기·재료·소화 시간·맵 비율·몬스터·경제·성장·카드 해금·광고·세이브·안드로이드 네이티브.
- 캐릭터 애벌레 시트에서 정확한 스프라이트와 모든 모션을 개별 추출해 넣는 작업. **게임 속 캐릭터는 승인 원본을 참고한 임시 Canvas 벡터 캐릭터**이며 최종 완성 그래픽 아님.
- 개인 캐릭터 카드 디자인 등급 프레임은 게임 안에서는 숨김.
- 사진은 유해나 첫 단독 얼굴 원본을 테스트용으로 포함함. 코드는 실제 앱이 아니라 데모임.

## 검증
- Chromium Playwright: 2026-11-22.
- 시작 후 내 땅 19.2%; 내 땅 내부 이동 성공; 외부 버튼 없이 이동 차단; 버튼 누른 외부 절단 시작 성공.
- 연속 8회 갉아먹기 → 소화 1.85초 시작, 소화 중 입력 차단 확인.
- 갈고리/U자 절단 후 내 땅 연결 → 영역 낙하 및 확보율 증가 31.2% 확인.
- 자동 시연에서 자연스럽게 세 번 소화 후 1회 연결 → 점령률 40.4% 확인.
- PC 1100x800과 모바일 390x844 렌더·레이아웃 및 JS 콘솔 오류 검사 통과.

참고: 데모 레이아웃은 최신 사용자 피드백을 반영해 더 수정할 예정.
