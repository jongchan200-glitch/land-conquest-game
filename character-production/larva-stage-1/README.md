# 와구와구 · 1단계 애벌레 검수실

index.html을 브라우저에서 열면 실행된다. 설치나 외부 리소스 요청은 필요 없다. 재생 위치, 배속, 장면 선택, 한 입씩 확인, 머리 확대, 소리를 조절할 수 있다.

## 제작 원본

design.png는 승인된 설계 시트다. parts/에 피부, 눈 두 장, 입 주변의 검은 수염 링, 한 개의 더듬이와 구슬 그림을 보존했다. extract.py는 Python, Pillow, NumPy로 시트에서 이 그림들을 다시 추출한다. 검수 HTML에는 같은 그림이 내장되어 있다. index.html의 head 함수에서 입과 두 볼의 변형을, bodySegment에서 마디·발·무늬를 수정할 수 있다. 그림을 수정한 뒤에는 pack.py로 내장 PNG를 갱신한다.

## 동작 연결

경로는 꼬리에서 머리 방향의 2D 중심선이다. 누적 거리로 위치를 찾고 마디 사이에 연속된 피부를 그린다. 마디의 크기는 뒤로 갈수록 줄어든다. 여덟 번째 입 뒤 .64초 삼킴과 2.66초 소화를 차례로 재생한다. 팽창은 중심선의 진행 비율을 따라 이동한다. 복귀 경로의 머리가 자기 영역 안에 도달한 후 꼬리부터 경로를 회수한다.

이 검수실은 고정 사선 시점의 미리 정한 경로를 쓴다. 기존 게임의 실제 입력, 충돌, 점령, 저장 코드는 호출하지 않는다. 향후 연결 지점은 beginBody/traceBody의 경로와 fullness/biteMax, beginSwallow/updateGut/emitGas, sealTrail이다. 검수 화면의 크래커와 시간은 연출 확인용이다.

review.png는 8개 시점의 실제 브라우저 렌더, mobile.png는 390px 폭에서 여덟 번째 입을 확대한 화면이다.
