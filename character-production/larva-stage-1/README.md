## 렌더러

createWorkLarva(canvas)를 한 번 호출해 렌더러를 만든다. draw에 머리와 몸통을 함께 그리는 상태를 전달한다. Canvas 2D와 WebGL이 필요하다. 원본 bodySegment가 각 마디의 피부, 무늬, 그림자색, 움직이는 작은 발을 동적으로 텍스처에 그린다. 고정된 여덟 텍스처 영역이 경로의 접선·법선으로 만든 삼각형 메시를 따라 늘어난다. 여분의 길이는 꼬리 쪽에 더 많이 배분하고 최대 너비 감소를 제한한다. 곡선을 더 정밀하게 그리기 위한 메시 꼭짓점 수는 경로 길이에 따라 달라진다. 머리는 원본 head 함수를 사용한다.

## 후속 게임 연결

현재 검수실과 같은 좌표 크기에서 다음처럼 호출한다. line은 꼬리에서 머리까지 연속된 화면 좌표 배열이다. 기존 몸통과 얼굴을 그리는 호출을 승인된 시험 모드 안에서 함께 대체한다. 기존 플레이어 이동과 충돌 업데이트는 그대로 둔다.

    const larva = createWorkLarva(characterCanvas);
    larva.draw({line, time, direction, fullness, bite, lift, boluses, gas});

- line은 이동 기록에서 화면 좌표로 변환한 {x,y} 배열이다. 마지막 점은 실제 머리, 첫 점은 애벌레의 실제 꼬리다. 출발 순간 직전의 휴식 몸통 경로를 보관하고, 그 끝에 bodyLine의 이동 기록을 이어 붙인다. 출발 시 길이 0인 절단선만 넘기면 꼬리 고정을 재현할 수 없다. 기본 자세 길이는 렌더러 좌표 146이고, 타일/카메라 배율은 캔버스 변환에서 적용한다.
- time은 초, direction은 왼쪽 1 또는 오른쪽 -1이다. fullness는 먹은 수/biteMax로 정규화한 볼 크기다. bite와 lift는 각각 씹기·삼킴의 0~1 진행 강도다.
- boluses는 머리 0에서 꼬리 1로 흐르는 소화 진행도 배열이다. gas는 꼬리 반동의 0~1 진행도이고 비활성일 때는 -1이다. 게임은 기존 emitGas 위치와 파티클을 계속 쓸 수 있다.
- 복귀 시에는 저장한 절단선에서 뒤쪽 길이를 점차 회수한다. 선을 한 프레임에 비우지 않는다. 배경, 음식, 효과, 저장, 점령 상태 관리 등은 캐릭터 렌더러 밖에 있다.

## 검수 기록

work-original.html을 다시 열어 원래 head, bodySegment, frame 실행을 확인했다. 수정본의 기본형, 첫 입 전후, 곡선, 직각 굽힘, 최대 늘림, 소화, 꼬리 방귀, 수축을 브라우저로 재생했다. review.png와 corner-first-bite.png는 검수실 렌더를 직접 캡처한 것이다. mobile.png는 브라우저 너비 390px에서 여덟 번째 입을 확대한 화면이다. 실제 게임 데이터 연동과 기기 실측은 후속 단계다.

extract.py는 design.png에서 얼굴 파츠를 추출하고, pack.py는 편집된 PNG를 새 렌더러에 내장한다. 복구한 원본 HTML은 이 과정에서 바뀌지 않는다.
