# 땅따먹기 v0.2.7 — 기존 캐릭터와 몸통 일체감 / 끊김 개선
작성일: 2026-11-23

## 사용자 지적의 정확한 의미
- 사용자가 90도나 대각선으로 꺾은 것은 의도적인 시연임. 경로를 꺾은 것이 문제라는 해석을 철회함.
- 문제: 확정 캐릭터의 전체 몸이 그림으로 다시 겹쳐 그려지고, 새로 그린 길게 늘어나는 몸통과 재질·각도가 달라 서로 따로 움직임.
- 이동 조작이 칸 경계에서 오래 멈췄다가 다시 출발하는 stop-go 현상.

## 실제 적용 변경 (index.html 화면·애니메이션·아날로그 속도에 국한)
1. 원본 `assets/worm_expressions.png`는 1바이트도 수정하지 않음. 애벌레가 몸을 늘리고 있을 때 원본 옆모습(표정1)의 머리 부분만 런타임 임시 캔버스에서 부드럽게 마스킹해 그림. 원본 몸통과 새 몸통을 중복 출력하지 않음. 후진/곡선에서도 머리 방향은 몸통 실제 끝 경로의 접선에 맞춤.
2. 기존 전체 스프라이트를 5, 6, 9 등으로 순간 교체하던 방식은 몸이 늘어난 상태에서는 없앰. 먹거나 삼키는 동안 같은 머리 그림에 부드러운 미세 수축 효과만 입힘. 몸속 음식 덩어리와 꼬리 가스 애니메이션은 이전 승인 구현 유지.
3. 긴 몸통 경로를 1프레임에 수백 회 각각 처음부터 반복 순회하던 `bodyVisualLine` 알고리즘을 누적 거리 기반 선형 보간으로 변경. 표시 점수도 최대 136개로 조절, 기존의 프레임 끊김을 줄임. 명암을 길이 방향이 아닌 몸통 단면 방향으로 조절, 각 마디의 명암을 부드럽게 정리.
4. 몸통 1칸 가량부터 카메라 추적을 머리 중심에서 몸 전체 중심으로 갑자기 바꾸던 부분을 길이에 따른 완만한 보간으로 변경.
5. 갉아먹을 때 0.62초씩 타일 경계에서 멈추고 빠르게 전진하는 대신, 미점령 영역에서 느리게 계속 전진하며 타일 경계에선 짧게 씹도록 조정. 자기 영토에서의 이동 속도는 그대로. 포만 최대 8회, 최초 몸 길이 15칸, 소화, 점령, 몬스터 피격, 저장/아이템/사진/상점은 변경 안 함.

## 브라우저 테스트
- Playwright Chromium 모바일 390×844 실기기 비율의 웹브라우저에서 실제 HTML / 원본 PNG 아틀라스를 로드하여 55프레임 애니메이션 연속 녹화, 화면 확대 확인.
- JS 오류 0; 실제 후진 시 몸 길이 감소; 8/8 포만 시 강제 꿀꺽 정지 후 재개; 음식 덩어리가 꼬리까지 도달하여 뿡!; 최대 15칸에서 반동 복귀 및 점령률 유지; 작은 폐곡선 점령 14.71%→15.44%; 몬스터 피격 시 체력 3→2; 레벨업 시 최대 길이15→19 검증.
- 프레임별 캐릭터+몸통 그리기 소요 시간: 이전 v0.2.6 약 0.9ms/프레임, 개선 v0.2.7 약 0.16~0.3ms/프레임(동일 컨테이너 Chromium 조건, 사용자 갤럭시 실제 FPS를 뜻하지 않음).
- 갤럭시 실기기에서의 멀티터치와 실제 GPU 드롭 프레임은 사용자가 최종 확인해야 함. 최종 아트적 일체감을 보장하는 것이 아니라 기존 원본을 재사용해 불일치를 줄인 패치임.
