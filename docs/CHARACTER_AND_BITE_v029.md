# 땅따먹기 v0.2.9 — 원형 수염과 자연스러운 한 입

## 사용자 명시 요구
- 애벌레의 시그니처는 **원형 수염**이다. '쿠션 머리'나 코수염이 아니다. 입 주변을 감싸는 가느다란 이중 원형 고리. 굵은 입술이나 가짜 코로 바꾸지 말 것.
- 홈에서 360도 돌아가는 3D 캐릭터에도 반드시 수염 고리가 있어야 한다. 캐릭터 한 바퀴 회전 시 종이처럼 납작해지는 효과 금지.
- 게임 기본 표정은 입을 다문 귀여운 얼굴. 액션 버튼 한 번 탭 시 앞으로 몸을 늘리고 ‘앙’ 한 입 먹고 ‘아그작’ 씹은 뒤 입을 닫는다. 제자리에서 반복하며 입만 여닫는 것 금지. 길게 누르면 기존 연속 갉아먹기도 가능.
- 앞서 확정된 8입 포만, 15칸 최대 몸길이, 소화 덩어리·방귀·자동 수축, 360도 조이스틱, 몬스터 사망, 아이템 상점, 저장, 수집 카드는 유지.

## 구현
- 기존 `assets/worm_expressions.png` 원본 파일 보존. 게임 동작 중 승인된 옆모습 머리 이미지에서 **입 안쪽만** 임시 Canvas 레이어로 덮어 기본 닫힌 표정을 만들어 쓴다. 눈·더듬이·피부·기존 원형 입 주변 특징은 보존한다. 먹는 순간에는 **동일 원본 얼굴**의 입 크게 벌린 그림만 투명도 보간하며 동작시켜 눈과 얼굴이 교체되지 않는다.
- `biteMotion`: 한 입마다 닫힘→크게 열기→씹으며 닫기→작게 한 번 더 씹기→닫힘 상태. 기존 가루·효과음과 갉아먹은 조각 표시 유지.
- `tapGrace/tapFollow`: 버튼 짧은 터치 한 번으로 진행 방향으로 한 칸 먹는 동작을 완료하고, 새로 열린 공간 안쪽까지 머리/몸통이 따라 전진. 연속 버튼 유지와 기존 손가락 조이스틱 조작과 공존. 외부 무료 이동/다음 조각을 무제한으로 자동 먹는 동작은 금지.
- 홈 캐릭터 실제 WebGL 3D 메시의 입 앞쪽에 입체 이중 원형 수염 고리와 입 다문 미소 추가. Canvas2D 대체 렌더러에서도 3D 부피와 회전 유지. 돌렸을 때 머리가 화면 밖으로 잘리는 문제 완화. 기존 홈 5개 탭 및 상점 유지.
- 서비스 워커 캐시 `land-conquest-v029-20261123` 갱신. `index.html`, `home3d.js`, `home.js`, `sw.js`만 수정하고 원래 3D 자료와 게임 원본·기존 백업·저장 데이터 구조는 보존.

## 브라우저 검수
- Playwright Chromium 모바일 390×844에서 원본 assets 사용, 클릭 1회 = 포만 0→1 정확히 한 번, 머리 약 0.87칸 전진, 입 열림 수치 약 0.5~0.98로 변화한 후 0으로 복귀, JS 오류 없음.
- 본편 로직 8번째 먹기 때 소화 잠금 활성화, 다음 이동 불허, 소화 종료 후 잠금 해제 검증.
- 홈 캐릭터 360도 회전 GIF 생성, 캐릭터·상점·코인·기록·설정 5탭 확인, 실제 40코인 상점 강화 구매가 보유 65→25 및 업그레이드 증가함 확인.
- 제한사항: 실제 삼성 갤럭시 GPU/WebGL과 손가락 연속 동작 품질은 사용자 실기기 평가 전. 기존 승인된 2D 원본 아트와 홈을 위한 새 입체 3D 모델은 아직 픽셀 단위로 완전히 같은 외형이 아님. 홈 3D는 구현용 시제품이고, 실제 출시용 아트 완성 검수는 별도.
