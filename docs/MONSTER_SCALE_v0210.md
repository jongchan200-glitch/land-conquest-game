# 땅따먹기 v0.2.10 — 몬스터 대형화와 성장 크기 대비

## 사용자가 명시한 핵심 의도

- 현재 보이는 몬스터는 향후 거대한 월드에서 가장 작은 등급에 해당한다. 지금 카메라 줌이 커서 상대적으로 커 보이지만, 월드를 앞으로 약 20배로 넓히면 화면에서 아주 작게 보일 수 있다.
- **현재 몬스터들은 v0.2.9 대비 약 2~3배 커야 한다.** 특히 첫 몬스터도 충분히 크고 위압적으로 보여야 한다.
- 몬스터를 레벨이 오를 때마다 실제로 줄이는 게 아니라, **내 애벌레가 레벨업으로 크게 성장하여 동일한 몬스터가 상대적으로 작아져 보이는 것**이 핵심이다.
- 향후 월드 약 20배 확장은 장기 설계 방향일 뿐, 이번 패치에서 맵 크기/카드/저장 좌표/충돌 그리드를 무리하게 변경하지 않는다.

## 실제 v0.2.10 구현

1. 몬스터 월드 반지름 2.5배 확대 (`MONSTER_BASE_MAGNIFICATION=2.5`, `monsterRadius` 함수). 바운서/방랑자 14→35px, 헌터 19→47.5px, 둥지형 25→62.5px. 모두 카메라 확대/축소와 관계없이 고유 월드 크기를 가짐. 기존 4종 색상/눈/다리는 보존하면서 입체 음영, 눈 하이라이트, 작은 입 표시 및 다리 움직임의 선 굵기를 실루엣에 맞게 손봄.
2. 몬스터 충돌 판정 확대: 기존 중심점 <0.75칸 규칙 대신 몸통 타원형 히트박스(`monsterHitRadius` = 몸통 시각 반지름 0.78배)와 애벌레 머리·늘어난 몸통·점령 절단 경로를 검사. 다리 끝부분은 꾸미기이므로 치명 판정 밖. 확대된 몬스터 몸통이 OWN/FALL 영토로 물리적으로 겹치는 정도를 줄이도록 이동 시 타원체 영역-타일 간 접촉 검증 `monsterCanOccupy` 추가.
3. 애벌레 시각 성장: 기존 Lv9 상한 1.55배를 `larvaLevelSize` Lv1 1배, Lv5 1.48배, Lv9 1.96배, Lv15 2.65배 상한으로 수정. 월드 좌표/점령/실제 속도/포만은 바꾸지 않음. 늘어나는 몸통도 동일 성장 계수를 머리에 가까운 부분에 적용하고, 출발 꼬리 부위는 좁은 형태를 유지해 머리·몸통 차이를 완화. 승인된 캐릭터 이미지 PNG는 변경 없음.
4. 갤럭시 화면의 카메라 줌이나 향후 확대 월드에서도 크기 관계는 월드 좌표 기준으로 유지. 몬스터 절대 반지름은 레벨업과 관계없이 동일하고 애벌레만 커져 상대적인 위협감을 다르게 느낌. 미래 몬스터 티어는 별도 설계.
5. 리소스: GitHub 원본 index.html만 기능 수정, sw.js 캐시 버전만 갱신, 승인 스프라이트/home.js/home3d.js/음악/상점/인벤토리/사진 카드/저장 구조/게임 룰 유지.

## 실제 Playwright Chromium 브라우저 검증 (390×844)

- 초록 바운서 크기 반지름 35px, 헌터 47.5px, 둥지 62.5px 확인. Lv1 성장계수 1, Lv9 1.96, Lv15 2.65. 동일 몬스터는 레벨 무관하게 반지름 일정.
- 홈에서 게임 시작, 기본 3하트, 몬스터가 멀리 떨어져 있는 상황에서 4칸 이동 시 사망 0. 경로 근처에 커진 몬스터를 놓자 3하트→2하트 및 CUT 경로 초기화, 좌표 본진으로 복귀 확인.
- 8입 가득 차면 소화 잠금 0.64초 발생, 입 단계/애벌레 성장 계산 정상. 홈 5개 메뉴 기존 유지. HTML 실제 브라우저 JS 오류 0.
- 화면 캡처 `/tests/large_monster_level1.png`, `/tests/large_monster_level9.png`, `/tests/monster_relative_size_comparison.png`; 검증 로그 `/tests/monster_checks.json`, `/tests/regression.json`.
- 주의: 갤럭시 실기기의 GPU/연속 터치 성능과 유저 체감 위압감은 아직 사용자 화면으로 최종 확인 전. 현재 크기를 더 높이거나 난이도를 조절할 여지는 남아 있음.
