# 땅따먹기 V0.2.8 — 지옥낙하 V0.7 홈 화면 구조 재활용
2026-11-23

## 실제 참조한 기존 게임
- 지옥낙하 GitHub `jongchan200-glitch/hell-drop`의 최신 `main/index.html`, `style.css`를 직접 읽고 구조를 참조함.
- 지옥낙하 순서: 상단 캐릭터 레벨/코인 → 중앙 타이틀/캐릭터 회전 쇼케이스 → 기록 → 시작 버튼 → 하단 캐릭터·상점·코인·기록·설정 5탭.
- 이 구성과 클릭 순서를 땅따먹기의 고정 홈 화면으로 구현. 독립 신규 게임이 아니라 기존 `main/index.html`에 홈 overlay를 추가.

## 적용된 부분
1. 게임이 처음 실행되면 기존 설명 팝업 대신 홈 화면 표시. 중앙 시작 버튼으로 **기존 게임을 중단했던 지점 그대로 계속**하고, 인게임 일시정지 메뉴에 홈으로 돌아가기 추가.
2. 캐릭터는 기존 승인이미지 `assets/worm_expressions.png`를 변경하지 않고, 그 특징인 복숭아빛 피부·큰 갈색 눈·더듬이·닫힌 입을 모델링한 **별도 3D 홈 전용 프로토타입**. 이미지 `rotateY`가 아닌 닫힌 입체 표면/앞뒤 깊이/보이는 면의 변화를 구현. WebGL 네이티브 3D 메시 + WebGL을 사용할 수 없는 브라우저용 3D 타원체 투영 캔버스 소프트웨어 렌더러. 좌우 손가락 끌기 360도 회전, PC 방향키 회전. 이것은 승인된 얼굴에 완벽히 일치하는 최종 3D 복제본이 아니며, 게임 내 기존 스프라이트와 몸늘림 그래픽은 수정하지 않음.
3. 기존 상점 `shopTile`/`buy`/`state.upgrades`/`save()` 를 그대로 호출. 세 가지 강화 구매 가격/보유 코인/게임 저장 반영. 홈 상점 구매 후 재렌더링만 홈용 분기 추가.
4. 하단 캐릭터/상점/코인/기록/설정은 모두 클릭 작동. 캐릭터 탭에서는 입체 회전, 구매되지 않은 단순 배지 **미리보기** 토글만 제공하고 실제 구매 아이템처럼 거짓 표기하지 않음. 기록은 현재 실제 점령률·이 기기 최고 점령률·몬스터 포획·스테이지·수집 카드 보기. 코인은 실제 보유 숫자와 획득 방법 설명, 광고/현금 결제 미연동을 명시. 설정은 실제 화면 전환, 조작·저장 안내.
5. 모든 게임 규칙·코인 거래·이미지·몬스터·실제 게임 조작과 저장 키·세계 진행은 보존. 확정 original sprite 수정 없음. 다른 게임 hell-drop 저장소 변경 없음. 코인은 게임별 독립.
6. 기존 홈 도입 설명·기존 게임 메뉴도 소스에 보존. 홈 스크립트가 실패하면 기존 팝업은 그대로 동작. 본 게임 포즈/이동 개선은 v0.2.7 그대로며 이번 커밋에는 해당 게임플레이 변경 없음.

- `index.html`: 홈 DOM 추가, 외부 `home.css`, `home3d.js`, `home.js` 참조, 메뉴에 홈 버튼 추가, 상점 구매 홈 재표시 분기만 수정.

## 브라우저 테스트
- 로컬 Chromium에서 네트워크 보안 정책 때문에 `localhost` 요청이 차단되어 실제 HTML/JS/CSS/원본 PNG를 인라인으로 합쳐 실행하는 동일 DOM 테스트 방식으로 검수.
- 390×844, 360×640, 412×915 모바일 배치에서 제목·캐릭터·시작 버튼·하단 메뉴가 스크린 안에 들어오는지 검수.
- Chromium은 WebGL이 비활성화되어 입체 메시를 소프트웨어로 실제 투영하는 fallback 실행을 녹화함. 반대편·옆·앞·뒤 360도 전부 화면이 다른 입체 모습임을 확인. 실기기 WebGL 렌더러 자체는 별도의 기기 테스트 필요.
- 홈 초기 표시 → 3D 드래그 → 상점 65코인에서 포만강화 40코인 구매하여 25코인으로 감소 및 upgrade capacity 1 저장 → 캐릭터 배지 시연 → 기록 표시 → 게임 시작 → 인게임 일시정지 → 홈 복귀 완료. 메뉴5개 및 유해나/아니카 카드 탭 정상. JS 콘솔/페이지 오류 0.
- 테스트용 스크린샷과 gif는 자동화 브라우저에서 캡처한 실제 결과임. 특히 현재 홈 3D는 시제품이므로 최종 확정 얼굴·몸 색감의 질감 개선 여지가 남음.
