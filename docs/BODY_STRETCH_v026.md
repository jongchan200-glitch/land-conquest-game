# 땅따먹기 v0.2.6 — 몸 늘림·소화 덩어리·강제 복귀

2026-11-23. 기존 GitHub `main/index.html`의 실제 화면·게임 규칙을 보존하고 애벌레 이동·소화 애니메이션과 몸 길이 규칙만 부분 수정.

## 확정된 규칙
- 꼬리는 자기 땅을 나가는 지점에 고정. 머리가 360도 방향으로 갉아먹으며 전진하면 그 **실제 구불구불한 경로**를 따라 복숭아빛 몸통이 길어진다. 정면·눈·입술 주위 얇은 수염선 등 기존 확정된 스프라이트의 얼굴은 재생성하지 않았다.
- 초기 최대 몸 길이: **한 입 이동 거리 15칸 상당**. 레벨당 2칸 증가. 몸 길이는 총 먹은 횟수가 아니라 현재 노출된 몸통의 **경로 길이**다. 이미 파먹은 길로 후진하면 줄어든다.
- 몸 한계에서 아직 자기 땅에 연결하지 못한 경우, **몸이 실시간으로 줄어들며 기존 곡선을 따라 원위치로 당겨진다**. 절단 흔적은 취소되고 목숨을 잃지는 않는다. 돌려받는 과정은 공격 노출 상태로 남는다.
- 초기 포만 한계: **8입**. 레벨업만으로 자동 상향되지 않는다(기존 `capacity` 업그레이드는 유지). **8번째 입에 짧은 꿀꺽 정지(0.64초)**가 발동한 뒤 다시 이동 가능.
- 음식 덩어리: 삼킨 뒤 **몸통 속에서 머리→꼬리 방향으로 이동**하며 볼록함이 작아진다. 꼬리 도착 시 연둣빛 가스 입자, 작은 '뿡!' 글자, 가벼운 소리·진동 효과. 몸통은 섬세한 명암·주름·미세 꿈틀거림으로 표현.
- 몸이 길어지면 화면에서 노출된 꼬리와 머리를 같이 볼 수 있도록 카메라가 부드럽게 줌아웃. 기존 조이스틱·기존 액션 버튼, 점령·낙하·코인·몬스터·생명·게임오버·카드·저장 등 기존 기능 유지.
- 몬스터가 노출된 몸통 또는 기존 CUT 절단선을 만지면 예전과 동일하게 목숨이 감소. 목숨이 전부 사라지면 게임오버. 무한 게임으로 변경하지 않음.
